# ЛР №1. Сегментация аномалий на аэроснимках полей

Курс «Нейронные сети», трек А, вариант 3 «Сегментация изображений», предметная область — сельское хозяйство.

Семантическая сегментация 8 типов аномалий и фона на аэроснимках сельхозугодий (Agriculture-Vision 2021: 512×512, каналы RGB + NIR). Сравниваются три архитектуры в одинаковых условиях обучения.

## Результаты

Тест — официальный `val` датасета (18 334 снимка), лучший по валидации чекпойнт каждой модели.

| Модель | mIoU | mDice | Pixel Acc | Параметры, млн | GFLOPs | GPU, мс/снимок | CPU, мс/снимок |
|---|---|---|---|---|---|---|---|
| U-Net + ResNet-50 | 0.423 | 0.574 | 0.762 | 32.5 | 86 | 9.7 | 201 |
| UPerNet + ConvNeXt-Tiny | 0.468 | 0.619 | 0.783 | 37.0 | 153 | 11.4 | 291 |
| DPT + DINOv3 ViT-S/16 | 0.506 | 0.657 | 0.807 | 25.6 | 62 | 15.3 | 176 |

Условия: 6 эпох, AdamW (lr 1e-4, weight decay 0.01), батч 16, разогрев 5% шагов + косинусное затухание, bf16, CE + Dice. GPU — RTX 4070 (bf16, батч 1), CPU — i7-12700F (fp32, 12 потоков).

Подробности, таблицы по классам и графики — в ноутбуке и в `outputs/`.

## Данные

[Agriculture-Vision](https://registry.opendata.aws/intelinair_agriculture_vision/), набор `cvpr_challenge_2021/supervised` (~21 ГБ). Первая ячейка раздела «Данные» в ноутбуке скачивает и распаковывает его сама. Вручную:

```
aws s3 cp s3://intelinair-data-releases/agriculture-vision/cvpr_challenge_2021/supervised/Agriculture-Vision-2021.tar.gz . --no-sign-request
```

Ожидаемое расположение — `../datasets/agriculture-vision/`, то есть рядом с папкой репозитория (задаётся в `src/config.py`). По условиям использования датасет не публикуется в репозитории; при использовании необходимо ссылаться на статью: M. T. Chiu et al. *Agriculture-Vision: A Large Aerial Image Database for Agricultural Pattern Analysis*. CVPR 2020.

## Запуск локально

```
python -m venv .venv
.venv\Scripts\pip install torch==2.14.0 torchvision==0.29.0 --index-url https://download.pytorch.org/whl/cu130
.venv\Scripts\pip install -r requirements.txt ipykernel
```

Далее выполнить ячейки ноутбука по порядку с ядром из `.venv`.

Требования: GPU от 12 ГБ (пик при обучении — 9.8 ГБ), около 45 ГБ на диске, полный прогон — около 6 ч на RTX 4070. На Windows видеопамять учитывается в общем лимите выделенной памяти, поэтому нужен достаточный файл подкачки.

Чекпойнты сохраняются после каждой эпохи в `checkpoints/` (в репозиторий не входят); при повторном запуске обучение продолжается с последней сохранённой эпохи.
