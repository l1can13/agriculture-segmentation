# Сегментация аномалий на аэроснимках полей (Agriculture-Vision)

ЛР №1 по курсу «Нейронные сети», трек А, вариант 3. Для каждого пикселя аэроснимка поля (512×512, каналы RGB + NIR) определяется фон или один из 8 типов аномалий: двойной посев, засыхание, разворотная полоса, недостаток питания, пропуск посева, вода, водоток, сорняки. Сравниваются три архитектуры в одинаковых условиях.

[Открыть ноутбук в Colab](https://colab.research.google.com/github/l1can13/agriculture-segmentation/blob/master/lr1_segmentation.ipynb) — открывается с сохранёнными результатами.

## Результаты

Тест — официальный val датасета (18 334 снимка). GPU — RTX 4070 (bf16, батч 1), CPU — i7-12700F (12 потоков).

| Модель | mIoU | mDice | Pixel Acc | Параметры, млн | GFLOPs | GPU, мс | CPU, мс |
|---|---|---|---|---|---|---|---|
| U-Net + ResNet-50 | 0.423 | 0.574 | 0.762 | 32.5 | 86 | 9.7 | 201 |
| UPerNet + ConvNeXt-Tiny | 0.468 | 0.619 | 0.783 | 37.0 | 153 | 11.4 | 291 |
| **DPT + DINOv3 ViT-S/16** | **0.506** | **0.657** | **0.807** | **25.6** | **62** | 15.3 | **176** |

DPT + DINOv3 лучше по всем метрикам качества и на 8 классах из 9, при этом самая лёгкая. U-Net быстрее только на GPU при обработке по одному снимку.

## Сравнение с авторами датасета

mIoU, % на официальном val. Результаты авторов взяты из статьи [Chiu et al., 2020](https://arxiv.org/abs/2001.01306), таблицы 3 и 5.

| Модель | mIoU, % |
|---|---|
| DeepLabV3+ (os = 16), авторы | 42.27 |
| FPN авторов, ResNet-50, RGB + NIR | 42.16 |
| FPN авторов, ResNet-101, RGB + NIR | 43.40 |
| U-Net + ResNet-50 | 42.33 |
| UPerNet + ConvNeXt-Tiny | 46.79 |
| **DPT + DINOv3 ViT-S/16** | **50.65** |

U-Net на уровне базовых моделей авторов. UPerNet превосходит лучшую из них на 3.4 п. п., DPT — на 7.3 п. п. Режимы обучения у нас и у авторов различаются, поэтому сравнение ориентировочное.

Условия обучения у всех трёх моделей одинаковые: 6 эпох, AdamW (lr 1e-4, weight decay 0.01), батч 16, разогрев + косинусное затухание, bf16, функция потерь CE + Dice, seed 42.

## Запуск

Датасет [Agriculture-Vision 2021](https://registry.opendata.aws/intelinair_agriculture_vision/) (~21 ГБ) ноутбук скачивает сам в `../datasets/agriculture-vision/`. По условиям использования в репозиторий он не входит.

```
python -m venv .venv
.venv\Scripts\pip install torch==2.14.0 torchvision==0.29.0 --index-url https://download.pytorch.org/whl/cu130
.venv\Scripts\pip install -r requirements.txt ipykernel
```

Нужен GPU от 12 ГБ. Полный прогон занимает около 6 ч на RTX 4070. В Colab первая ячейка сама клонирует репозиторий и ставит библиотеки, но полное обучение в бесплатном Colab не уложится по времени.
